# seqr-fcc-protein-folding
Code and data for a symmetry-extended qubit reduction (SEQR) theorem for FCC lattice protein encoding: a closed-form O_h reduction to 4(N-1)-5 qubits, a symbolic register-to-Ising pipeline, and validation on the amyloid-beta fragment KLVFFA in simulation and on IBM superconducting hardware.
